Frontend ↔ Backend Communication

The Complete Login-to-Render Journey

1
User → Frontend
"Opens login page, enters username + password"
2
Frontend → Backend
"POST /auth/login | { username, password }"
3
Backend → Keycloak
"Authenticate this user via OIDC"
4
Keycloak → Keycloak
"Validating credentials against realm users..."
5
Keycloak → Backend
"Valid. Here is Access Token + Refresh Token (JWT)"
6
Backend → Frontend
"Login success. { accessToken, refreshToken }"
7
Frontend → Frontend
"Storing tokens in memory/localStorage"
8
User triggers action
"Clicks on protected resource"
9
Frontend → Backend
"GET /api/events | Authorization: Bearer {JWT}"
10
Backend → Keycloak
"Validate JWT using cached JWK public keys"
11
Keycloak → Backend
"Valid. Claims: { roles: ROLE_ADMIN, sub: user123 }"
12
Backend (internal)
"RBAC check — @PreAuthorize ROLE_ADMIN ✓"
13
Backend → Database
"Execute query, fetch events data"
14
Backend → Frontend
"200 OK | { events: [...] }"
15
Frontend → Frontend
"Decode JWT, render Admin UI based on roles"
16
Frontend → User
"Shows UI with admin controls and events data"
